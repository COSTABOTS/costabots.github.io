WIDGET DE BRUMA · DEMOSTRACIÓN REAL

Reservar sin salir de la web.

Esta página recrea la web de Bruma. El widget es la tecnología COSTABOTS conectada al entorno DEMO.

La reserva se registrará en el entorno de prueba. No es una reserva para un restaurante real.

Al confirmar, la reserva se muestra en Manager Demo para que el equipo pueda gestionar el servicio.

BRUMA ASSISTANT · DEMOSTRACIÓN REAL

La conversación también forma parte del servicio.

Mientras el Widget permite reservar directamente dentro de la web de Bruma, Bruma Assistant acompaña al cliente en una conversación, resuelve dudas y también puede registrar la reserva en Manager.

Bruma Assistant utiliza la misma plataforma COSTABOTS y puede compartirse mediante un código QR o un enlace directo.

AUTOMATIZACIÓN DE MENSAJES · SIMULACIÓN FIEL

El seguimiento, en el momento adecuado.
